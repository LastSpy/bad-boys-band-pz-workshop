[h1]Bad boys Band — B42 + MP[/h1]
A large, tested Build 42 mod set that runs together without conflicts: Project Viewpoint (3D first/third person), Project A-Life NPCs, hundreds of vehicles, clothing, crafting, cooking, maps and QoL. For Project Zomboid [b]42.22.2[/b]: your own server, co-op or single player.

[h2]🟢 The whole set in minutes[/h2]
[list]
[*]Download [url=https://github.com/LastSpy/bad-boys-band-pz-workshop/releases/latest/download/PZ-3dpz-client.zip]PZ-3dpz-client.zip[/url], start Steam, close the game, unpack it and run [b]Install.cmd[/b].
[*]Pick a language, then [b]1 – First install[/b]. When Steam finishes the downloads, start the game: the mods are already enabled.
[/list]
The installer subscribes you to the set, removes nothing of yours, checks for clashing mods, adds the files ZombieBuddy needs, sets the game memory for your PC and enables exactly the set's mods. Run it again later: [b]2 – Update[/b] when the set changes, [b]3 – Settings[/b] for PZ_Optimization.

[h2]Hosting a server?[/h2]
Ready [b]Mods=[/b], [b]WorkshopItems=[/b] and [b]Map=[/b] lines for your .ini: [url=https://github.com/LastSpy/bad-boys-band-pz-workshop/tree/main/server-config]server-config[/url]. Your players only need the installer. True Ballistics, True Weathers Gameplay and PZ3D Minimap also need ZombieBuddy on the server.

[h2]Good to know[/h2]
[list]
[*]Subscribing alone is not enough: some mods need files in the game folder. Use the installer.
[*][b]PZ_Optimization[/b] (fewer stutters) left the Workshop; the installer takes it from [url=https://github.com/xD3I/PZ_Optimization]GitHub[/url], updates come from the game menu. Untested in MP by its author. [b]Paused[/b] until its author releases a 42.22 build.
[*]Viewpoint and ZombieBuddy are Java mods: a game update can break them, after a game update wait until the set is updated (now: [b]42.22.2[/b]).
[*]Crashes: switch Viewpoint upscaling away from DLSS; disable RTSS / MSI Afterburner hooking for ProjectZomboid64.exe; run [b]Crash-Report.cmd[/b] from the installer folder.
[/list]

[h1]Bad boys Band — B42 + MP (русский)[/h1]
Большая проверенная сборка модов Build 42 без конфликтов: Project Viewpoint (3D от первого/третьего лица), NPC A-Life, сотни машин, одежда, крафт, готовка, карты и удобства. Для [b]42.22.2[/b]: свой сервер, кооператив или одиночная игра.

[h2]🟢 Вся сборка за несколько минут[/h2]
[list]
[*]Скачай [url=https://github.com/LastSpy/bad-boys-band-pz-workshop/releases/latest/download/PZ-3dpz-client.zip]PZ-3dpz-client.zip[/url], запусти Steam, закрой игру, распакуй и запусти [b]Install.cmd[/b].

Установщик подписывает на сборку, ничего твоего не удаляет, ищет конфликты, ставит файлы ZombieBuddy, настраивает память игры под твой ПК и включает ровно моды сборки. Потом: [b]2 – Обновить[/b], когда сборка меняется, [b]3 – Настройки[/b] для PZ_Optimization.

[h2]Полезно знать[/h2]
[list]
[*]Одной подписки мало: части модов нужны файлы в папке игры. Используй установщик.

[*]Viewpoint и ZombieBuddy — Java-моды: обновление игры может их сломать, после обновления игры дождись обновления сборки (сейчас: [b]42.22.2[/b]).
[*]Вылеты: переключи апскейл Viewpoint с DLSS; выключи перехват RTSS / MSI Afterburner для ProjectZomboid64.exe; запусти [b]Crash-Report.cmd[/b] из папки установщика.
